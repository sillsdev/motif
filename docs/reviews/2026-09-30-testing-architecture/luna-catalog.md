1. Make the site home summaries derive from the shared help source and test that generation.
2. Resolve the UI help scope decision; then add UI entries and CLI lookup coverage only if direct per-UI help is required.
3. Correct the two verified documentation mismatches: ADR 0047’s descriptor consequence and the Handoff progress comment.

I do **not** recommend putting CLI invocation delegates into `CommandDescriptor`, routing the App through CLI JSON, or moving LibLCM types into Contract. The reviewed paths already share the typed command handlers; front-end lifecycle, parsing, gating, and rendering remain adapter work. The current manual catalogs cost coordination, but the parity tests make that trade visible without evidence that a larger refactor fixes an actual runtime break. No external best-practice claim was needed for these conclusions; recommendations follow the repository’s contracts and observed code.
