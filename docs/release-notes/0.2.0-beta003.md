# Motif 0.2.0-beta003

Motif helps you see which words your FieldWorks grammar can parse, inspect why a word did not parse, and collect changes to analyses before applying them to your project. This third beta is for the same invited testers. Motif is still a working demonstration: keep a FieldWorks backup and try it on a copy of your project first.

## What changed since beta002

- **Advanced AI mode (optional, off by default).** Open **AI assistants** and turn on Advanced AI mode to let Claude Desktop, Claude Code or Codex use Motif's project tools. An assistant can read your Known projects, draft a Proposal, check it with a Trial and revise it; it cannot Apply a Proposal. Motif installs its plugin in Claude Code and Codex for you; for Claude Desktop it adds Motif's server, and you upload the plugin ZIP it shows you. Restart an open assistant session after changing the setting.
- **Proposals page.** **Proposals** lists every set of changes you can review: what an AI assistant put together and the changes you collected yourself. Cards are grouped by what to do next (**Waiting for you**, **Needs another try**, **Not tried yet**), each with today's numbers beside the Proposal's. **Open** shows the project's pages with the Proposal beside today, and **Review changes** walks its changes in one list, with **Keep**, **Undo** and **Apply to FieldWorks project**. **Decline** keeps a Proposal you do not want as a record; a declined or withdrawn Proposal can be reopened, and a declined, withdrawn or superseded Proposal that never applied can be deleted. An applied Proposal is final and kept. Closed Proposals are hidden until you choose **Show closed**.
- **Default proposal checks.** Settings has a new **Default proposal checks** group. **Compare stored analyses** chooses how much of FieldWorks' stored analyses a grammar check compares: **Within a work budget (recommended)**, **Every word** (slower on large projects) or **Off**. It applies to the next grammar check.
- **Parsimony page (in Advanced AI mode).** Motif can check the grammar for places it could be tidier or more restrictive, such as repeated ad hoc restrictions or unused statements, and lists each finding with what was counted and how strong the evidence is. Opening the page never starts a check. Keep, defer or ask is staged like any change and written to FieldWorks as a Notebook record when you Apply; after Apply and Refresh, kept and deferred findings move to **Suppressed**.
- **The Word list scrolls sideways** when its columns do not fit a narrow window, instead of being cut off at both edges.
- **PanGloss 0.8.3 is bundled.** The grammar check always finishes its report and runs up to four times faster, and FieldWorks projects import faster. When the check of stored analyses reaches its work budget (see Default proposal checks), Warnings says so in plain words: nothing needs changing in FieldWorks, and the remaining words are checked when they are parsed.
- **More reliable on Linux.** Parsing on several threads now starts on Linux systems without a delegated control group (including WSL), still held to its memory limit.

The Windows Setup includes Motif, its command-line tools, PanGloss 0.8.3 and native dependencies. Download it from this release; no developer checkout or .NET SDK is needed. Linux x64 AppImage and macOS arm64 portable ZIP downloads are previews, built and checked on their respective systems. Automatic updates are not enabled, so install beta003 over beta002 explicitly; your Motif data and FieldWorks projects stay in place.

## Limits to know before trying it

- Motif reads the saved FieldWorks project. Save in FieldWorks, then use **Refresh** and **Parse all words** to measure your latest edits. Close FieldWorks before applying changes; Motif refuses Apply while FieldWorks owns the project.
- Motif writes nothing to the FieldWorks project until Apply. Selections, measurements, Proposals and changes not applied yet are stored separately by Motif.
- Motif is pre-1.0. An incompatible Motif store is refused rather than upgraded. **Delete this file and reopen** recreates a refused project store and loses changes not applied yet. These actions do not delete your FieldWorks project.
- **Apply before you update.** Changes you staged in beta002 but did not Apply are lost when beta003 first opens the project, because Motif's store changed shape. Apply them in beta002 first, or expect **Delete this file and reopen**.
- On Windows, a Draft saved before beta003 gets a new revision once, the next time it is saved. Its content is unchanged; Motif now stores the same text on every operating system.
- Results measured with an earlier PanGloss can differ from beta003's. Press **Parse all words** after updating to measure with PanGloss 0.8.3.
- A word that reaches its step limit has an incomplete search. Finding an analysis does not mean that the search finished. Parsing on several threads uses more memory at once than one thread did.
- Parser support and warnings come from the bundled PanGloss version. A grammar pattern that is unsupported or cannot be measured is not evidence that the word cannot parse.
- An AI Handoff, an assistant session and optional diagnostic details can contain real language data. Review them before sharing. Advanced AI mode sends nothing anywhere by itself; what an assistant sends to its own service is up to that assistant, and connecting an assistant runs that assistant's own installer. Motif keeps a local usage log of command and argument shapes; it has no usage-upload feature. Writing-system loading may make online language-tag lookups.
- Automatic updates are not enabled. Uninstalling Motif leaves your FieldWorks projects and Motif data in place.

See the [install guide](https://github.com/sillsdev/motif/blob/v0.2.0-beta003/src/SIL.Motif.Help/Content/en/guide/install.md) and the Help included in Motif for the first run, keyboard shortcuts, Advanced AI mode and recovery instructions.
