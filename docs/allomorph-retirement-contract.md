# Allomorph retirement contract

An author replaces listed forms with a sound rule as one Proposal, including how checked analyses and restrictions will move. Ambiguous destinations and incomplete replacements are refused before they touch the project.

Normative decision: [ADR 0057](adr/0057-explicit-allomorph-retirement.md). Ordinary identity comparison remains [ADR 0027](adr/0027-what-counts-as-the-same-word-analysis.md); [ADR 0026](adr/0026-order-is-declared-not-positional.md) governs declared order. This contract refines the reference-retarget and retirement family, not a competing mutation API.

## Portable authoring values

`SIL.Motif.Contract.Retirement` contains the pure closed types, codecs and structural validator. Contract has no LibLCM dependency. `allomorph-retirement.schema.json` and `allomorph-retirement.vectors.json` are embedded portable descriptions/fixtures for non-.NET callers.

`ReplaceListedAllomorphsWithRuleIntent` has exactly `format: motif-allomorph-retirement`, `version: 2`, `naturalClass`, `rule`, `retirements`, `operations`, and optional `display`. Unknown keys, duplicate JSON properties, unsupported versions/classes/kinds/roles and omitted required properties are errors. All nullable constructor properties remain required JSON properties; only `display` is optional. IDs follow Motif's 22-character suffix/network-order GUID contract. Prefixes are not semantic identity and aliases cannot evade duplicate/collision checks.

| Value | Closed meaning |
| --- | --- |
| `naturalClass` | `mode: create|reuse`, exact id, semantic name/abbreviation, nonempty distinct authored phoneme members, explicit null semanticDigest for create or expected digest for reuse. Segment-class support is bounded; feature classes/alpha expansion require a wider typed capability. |
| `rule` | New exact rule id and semantic name; nonempty ordered input/output phoneme ids; ordered left/right typed atoms (`segment`, `natural-class`, `boundary`) with exact ids; declared class must be used; explicit `first|last|before|after` placement with null or exact anchor; `enabled: true`. The complete enabled candidate is required, even if primitives create disabled objects internally. |
| `RetireAllomorphIntent` | One component per entry, with required scope `affix|stem`, retiredForms, roleReplacements, bundles and adhocReplacements. Compose multiple entries in the same coherent Proposal. |
| `AllomorphIdentity` | Exact id, entry, class `MoAffixAllomorph|MoStemAllomorph`, location `alternate` for a source and `alternate|lexeme` for a survivor, position `prefix|suffix|root|stem`, expected semantic digest and explicit StemName id/null. These are Baseline assertions requiring independent model validation. |
| `AllomorphRoleReplacement` | RetiredForm + exact MSA + **explicit** InflType id/null + whole expansionRole, with a complete surviving replacement assertion. Unique role key, compatible type/entry, no retired target or chain/cycle. |
| `RetirementBundle` | Exact bundle/analysis/wordform identities and role key. Every entry must resolve to exactly one role replacement; contradictory ownership or duplicate bundle destinations are errors. |
| `AdhocOccurrenceReplacement` | Rule id, closed field `FirstAllomorph|RestOfAllos|Allomorphs`, ordinal null for First or nonnegative occurrence for other fields, retiredForm and complete replacement assertion. This independently authored destination may differ from the bundle role destinations. |
| `RetirementOperationBinding` | Exact operationId, closed review slot, target, explicit member/null, dependsOn ids. A binding certifies the authored dependency graph and is not executable property input. The composer must bind it to actual semantic envelopes and full field footprints. |

The graph slots are `class-create`, `class-members`, `rule-create`, `rule-input`, `rule-output`, `rule-left`, `rule-right`, `rule-placement`, `rule-enabled`, `bundle-morph`, `adhoc-first`, `adhoc-rest`, `adhoc-legacy`, `alternate-delete`. A deletion targets its entry and exact member; other slots have null member. Each required semantic slot has one binding and each bound operation id is unique. Class reuse emits no class writes. The creation/member edges, rule creation/content edges, class→rule edges, complete rule→retarget edges and rule/every-retarget→delete edges must be explicit or transitively present. Array order is irrelevant. Cycles, unknown dependencies, missing/extra bindings and duplicate writers refuse.

These are a **bounded contract certificate**, not a replacement for the actual operation catalog. Lowering must reconcile the reviewed slots with all concrete generated operations, including class name/abbreviation/member writes, owned contexts/RHS and rule enable/placement. If a slot needs several actual operations, the composer binds the complete expansion and its concrete DAG in the Proposal's verification record; no synthetic barrier operation may stand in for completion. Finalized Proposal operations and their dependencies, not this certificate alone, govern the engine. The actual composer/operation adapter is a subsequent implementation gate.

`AllomorphRetirementCodec.IntentDigest` is SHA-256 over RFC 8785 canonical semantic **authoring** JSON. Only display title/description is excluded. It includes all mappings, baseline semantic assertions, reference destinations, class/rule meaning and dependency declarations. Entity ids normalize to network-order suffix identity; plain semantic strings normalize to NFD. Members, components, mappings, bundle/occurrence declarations, graph bindings and dependency sets are sorted by canonical JSON content. Input/output/context sequences preserve linguistic order. Sorting graph declarations never invents an edge. The eventual Proposal still uses its ordinary intent digest over generated semantic operations; the authoring digest is a distinct binding.

Bounds are 16 MiB per authoring envelope, 256 entry components, 4,096 source forms per component, 65,536 mappings/references/bindings per list, 256 context atoms per side and 256 dependency depth. Larger authoring requests must be refused explicitly, not silently truncated. These bounds do not authorize sampling mandatory verification cases.

## Independent frozen-expectation input

The original reading must survive even after a scratch project deletes its form. Verification therefore consumes a frozen before record and never reconstructs that record from the candidate.

The required input shape is `FrozenExpectationSet` with contract **`frozen-expectations/v1`**, described in `frozen-expectations.schema.json`. `FrozenExpectationCapture` reads the declared affected wordforms from the source cache and computes the case, human-input and manifest digests; `FrozenExpectationCodec` validates the closed value and preserves its original records. Capture is bound to the source Baseline, but the caller still has to prove that the affected-wordform manifest came from the complete retirement census. The capture must supply:

- The exact source `BaselineToken`, independent humanInputDigest, complete manifestDigest and expectationRevision.
- Every affected original wordform's populated vernacular surface/WS case, a unique case id, nullable wordform identity, explicit InSelection/HeldOut flags and all its original Approved readings, including unaffected alternate readings. Additional held-out cases stay separate. All wordforms with an Approved referring bundle are mandatory even outside Texts/Selection.
- For each reading: stable reading id, original analysis id where present, approved/disapproved/unknown/mixed Opinion, provenanceDigest binding retained sense/category/features/glosses/Text links and the actual human evaluation ids, agent ids and Approved/Disapproved memberships. No parser Opinion substitutes for these.
- Ordered original morphs: bundle id where present, authoritative Form/MSA/explicit InflType, role, conditional GuessedString/GuessedWritingSystem, and each original WS bundle text with rich-content digest. General frozen input can preserve whole/prefix/suffix roles and guessed comparison data; ordinary retirement accepts only whole, unguessed mapped bundles. Plain surface/guessed text is NFD; captured MultiString uses LibLCM NFSC and formatting digests.
- All project-backed reviewed negatives independently of wordform existence: case id, Notebook revision id/content digest, WS/surface/context, surface or exact ordered reading target. A surface target has no morphs. Original revisions are retained when an explicit translated revision is authored.
- Explicit unavailable reasons. Such input remains inspectable but `RequireComplete` refuses a complete-verification claim. Empty negative data is an explicitly reported evidence gap, not a manufactured negative universe.

These are closed serialization values, not trusted claims of exhaustive capture or immutable collection implementations. The producer owns copying/freezing them and computes the manifest/human digests; the consumer verifies their binding against the exact source. The model census must prove the mandatory set is complete. JSON round-trip separates retained original values from later scratch mutations.

`RetirementExpectationTranslator` preserves the source set and creates a separate translated set only for affix components with an exact role mapping, a matching Proposal operation, and the corresponding native Morph and Form effects in the bound Dry Run. It retains every case, reading, Opinion, provenance digest and evaluation membership; unrelated morphology stays unchanged. It refuses incomplete identities, guessed retargets, missing or mismatched Form-copy evidence, same-word many-to-one collisions, and contradictory Approved/Disapproved results. A staged human revision or retraction changes only the translated negative expectation when it replaces the exact frozen Notebook revision; the original remains in the pair, and its morphology identity is never retargeted. `RecipeVerification.Compare` accepts this pair, checks the original against the before Assessment and the translated set against the after Assessment using the unchanged ADR 0027 matcher. Its older identity-mapping parameter still refuses nonempty mappings. No fallback joins or live/scratch-derived before oracle are permitted.

The Report inputs contract can retain the complete pair, mapping digest, Proposal intent digest, Dry Run before-footprint digest and Dry Run effect digest under `retirement-expectation-translation/v1`, described in `retirement-expectation-translation.schema.json`. Existing Reports without that optional field continue to round-trip unchanged; no stored Report is rewritten.

## Stem authoring boundary

A stem alternate can share the same explicit replacement recipe while preserving its primary dictionary form. Valid authoring input advertises the additional proofs that are still required before such a change can run.

`AllomorphRetirementScope.Stem` serializes only as `stem`; `Affix` only as `affix`. Each component requires one scope. Affix permits MoAffixAllomorph with prefix/suffix and null stemName. Stem permits MoStemAllomorph with unbound root/stem, the same position and exact stemName id/null on source and every role/ad hoc destination. Equal canonical suffix identities are equal even with different prefixes. The digest includes scope and stemName assertions. Unknown/numeric scope, class/scope mismatch, unsupported morph type, changed stemName, primary source and non-whole roles refuse. Stem role InflType must be explicit null; variant expansion is unsupported.

A form semantic digest must bind the full form meaning, including exact morph type/abstractness, normalized WS alternatives and resolved PhoneEnv meaning. Stem selection requires independent contextual evidence for name owner/Regions/feature definitions, sibling required/excluded names, relevant FromStemName consumers, entry/MSA meaning and ordered surviving forms. Equal name ids do not establish effective gate equivalence. New model validation must refuse absent or changed evidence, incompatible/borrowed MSAs, unproved environment-to-rule correspondence, unsupported entry/sense expansion and last-loadable-realization loss. Structural parsing cannot establish any of those model facts.

Whole stems in ordinary compound analyses remain exact ordered bundle roles. Stored MoDeriv.StemForm and MoCompoundRuleApp.LeftForm/RightForm references remain unsupported writers and block deletion. Both directions of LexEntryRef component links and their variant/complex-form meaning require an expansion-context census even when no MoForm reference exists. No compound/variant reconstruction or gate edits are implicit effects.

The same IMoForm native setter supplies underlying stem bundle text. Every changed/cleared WS alternative and all retained evaluation/Text/surface identities need stem-specific package-pin tests; existing affix proofs cannot satisfy `stem-bundle-form-effects`. Frozen expectation v1 and review-statistics shapes are unchanged. Their producers must enumerate all affected stem/compound wordforms, all Approved readings and WS cases, and independent held-out/conditioning controls, preserving the original oracle. Unsupported expansion and missing attribution stay unavailable.

The current authoring contract is `allomorph-retirement/v2`; v1 inputs are refused and must be regenerated. Required scope and stemName have no defaults or compatibility reader. `AuthoringScopes` lists declared shapes, not executable capabilities. `RequiredCapabilitiesFor(Stem)` includes every common requirement plus `stem-selection-gate-equivalence`, `stem-environment-rule-correspondence`, `stem-expansion-context-census`, `stem-bundle-form-effects` and `frozen-stem-reading-verification`. Unknown enum values refuse. `CanApply` remains false for both scopes. The retained-form R2 composer continues to accept only Affix and refuses Stem before producing operations.

See the [ADR 0057 amendment](adr/0057-explicit-allomorph-retirement.md#amendment--ordinary-stem-alternate-forms) and [copied Sena inspection](research/sena-stem-retirement.md) for exact forms, environment semantics and the acceptance boundaries.

## Census, effects and review records

The independent entire-project census includes bundle Morph, flat/grouped First/Rest/legacy ad hoc occurrences, disabled records, custom/native references from any class and owned dependents. Missing destinations refuse with retired id, complete unresolved rows/counts, distinct unresolved Approved analyses and distinct ad hoc rules. Zero in those two headline categories never proves that all references are handled. Unsupported routes and active-prohibition denotation failures are separate structured reasons. Newly discovered references require re-authoring, not an automatic destination.

Native ordinary Morph retarget copies replacement bundle text and clears missing WS alternatives. All secondary effects are part of the footprint and actual scratch read-back. Reject pattern/guessed/customized/rich bundle content and populated missing replacement WS alternatives. Preserve complete human evaluation membership and all other analysis, wordform and Text data. Never emit a redundant ordinary Form setter or use LibLCM clearing to complete retirement.

`RetirementReviewStatistics` and `RetirementReviewCodec` define unique bundle, analysis and wordform counts, each with disjoint Approved/Disapproved/Unknown/Mixed partitions; wordforms containing differently judged readings enter Mixed. The portable shape is `allomorph-retirement-review.schema.json`. Assessed form/WS cases are separate from wordforms. All four ad hoc rows partition grouped/flat and enabled/disabled, counting rules separately from occurrences. Other-reference/owned-deletion counts and bundle-text changed/cleared alternatives are explicit. Exact detector before/after n/N, finding id, relevant evidence digests and resolved result stay separate from parse preservation. Numeric closure and partition checks cannot prove that counts reconcile with the entire detailed manifest named by DetailManifestDigest; the producer must establish that, without sampled examples or author estimates.

The retained verification record/Report must bind authoring and Proposal intent digests, source Baseline, full census/mapping/detail/case digests, original and translated expectations, actual Dry Run effects, before/after Assessments, per-reading completion/matches and source-bound rule-attribution witnesses. Direct Trace/derivation evidence or a completed exact-rule-disabled counterfactual is required for changed realization claims. Large manifests use bounded jobs aggregated without omitted required cases. Rebuilt candidate artifacts must genuinely resolve the original finding without Suppressed/filter/loader omissions.

## Capability and operation-family completion

The contract is reviewable before the engine can carry it out. Its capability metadata advertises the missing proofs explicitly, so a client cannot mistake valid JSON for a supported Apply.

The R2 adapter composes exact bundle Morph and ad hoc allomorph-reference retargets while retaining every old form. It reads the native Morph setter back as separate Morph and Form effects, records ordered ad hoc sequences by ordinal, and binds the live reference census and affected reading context into Dry Run and Apply preflight. Its tests pin native text copying and clearing, rich/custom-text and missing-writing-system refusals, analysis/evaluation/Text identity, reference and semantic-context drift, disabled rewrites, and only provably same-denotation active rewrites. R2 does not create the rule, freeze or translate expectations, delete forms, or claim a completed retirement recipe.

| Operation-family element | R2/R3 state |
| --- | --- |
| Closed payloads, bounded same-entry validation and lowering | Delivered for ordinary prefix/suffix bundle Morph and First/Rest/legacy ad hoc references. |
| Dry Run effects and read-back | Delivered for bundle Morph plus native Form alternatives and exact ad hoc field sequences. |
| Snapshot/diff and conflict checks | Delivered for ordered sequence slots, bundle text, and census/reading-context drift, including replacement form, MSA, Opinion and Text-use changes. |
| Apply and rollback/save-open evidence | Bundle Apply/read-back, save/open, and whole-Proposal rollback after bundle Morph/Form and ad hoc sequence mutation are covered. |
| Frozen expectations and paired comparison | R3 delivers source-bound frozen capture input, exact-role translation with Dry Run Form-copy evidence, explicit Notebook revision/retraction handling, Report input storage, and the original-before/translated-after comparison path. The Mbugwe sample proves the bounded Dry Run path on an isolated copy. |
| Complete family coverage, deletion and recipe acceptance | R4 still owns retained-form deletion and whole-unit save/open/rollback proof. R5 still owns complete parser recipe execution, finding resolution and rule attribution. No full retirement success claim is available. |

`AllomorphRetirementCapabilities.CanApply` is false. No new command is registered and no retire/delete method is exposed on an agent surface. The [shared Help draft](help-drafts/replace-listed-allomorphs-with-rule.md) is reserved for the eventual Released composer, with title/description metadata alongside it. It must ship through the shared Help catalog when that composer ships, not promise available execution now.

| Closed schema/prose | This contract, portable vectors and strict unknown-key/id/null/role/composition tests; narrower segment authoring boundary explicit. |
| Validation/lowering | Pinned complete census, same-entry/source/survivor/morph/gate checks, bundle-text eligibility, exact ad hoc denotation, concrete class/rule→retarget→delete DAG, one writer per final slot. |
| Dry Run effects | Four linked review groups from real scratch read-back, every text clear/change and preserved Opinion, complete enumerated counts. |
| Apply/read-back | One UoW, no dangling/unmanaged references before deletion; save/reopen retains identities/evaluations/Text/surface/constraints/judgments and matches supported copied bundle text. |
| Conflict/Rebase | Added/edited reference, sequence, source/replacement, MSA/InflType/Opinion, negative/schema edits refuse; no implicit mapping growth or intent change. |
| Snapshot/diff | Exact GUID changes and secondary text effects, full touched sequence/ownership/judgment footprint; translation separate from mechanical diff identity. |
| Positive/negative | Owner suffix pair and independent alternation families; every Approved reading incl. unaffected/outside-Selection cases; all unsupported forms/text/routes/collisions/dependencies refuse without writes. |
| Rollback | Faults after class/rule/context creation, each retarget/text copy and deletion restore full semantics, evaluation membership and owned objects. |

No package behavior, parser causality, rollback or full operation-family completion is asserted by the pure contract tests. The integration slices must prove them against the actual pins before changing the capability or registering a Released command.
