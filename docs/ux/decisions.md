# Window decisions

These decisions preserve the current window choices and record the work that belongs with Proposals.

- The Matrix **Review** preset chip keeps its name, and **Fix These First** stays below the Matrix.
- Review changes checks for a lost approved reading on words shared by the two Assessments and compares
  parse coverage over those shared words. When the word sets are equal, a new failing word that dilutes
  parse coverage is a regression. When they share no words, the window says the check could not compare.
- Board 14, a Proposal's own Overview with before-and-after evidence, is carried into the Proposals epic.
