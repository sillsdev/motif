# Swahili morphology for the synthetic Bantu teaching sample

**SYNTHETIC EXAMPLE.** The eventual FieldWorks language data is generated to demonstrate Motif. It is modelled loosely on Swahili, but it is not real Swahili, has not been checked by speakers, and must not be used as a description of any language. This note analyzes attested Standard Swahili patterns to guide that synthetic example; it is not the example's lexicon. [The sample plan](../../superpowers/plans/2026-09-26-site-home-learn-samples-plan.md) identifies the sample as `synthetic-bantu`.

## 1. Plain-language overview

Swahili often signals singular and plural by changing a prefix on a noun: *mtu/watu* “person/people,” *mti/miti* “tree/trees,” and *kitabu/vitabu* “book/books.” A verb uses its own markers to show who or what acts, when the action happens, and sometimes who or what is affected. Those verb markers have a fixed order, and a noun's visible prefix is not necessarily the same as the marker used for agreement on the verb. This gives the teaching sample two connected jobs: identify the noun's class and number, then put the matching agreement marker in the right verb slot. [TS01, chs. 4, 20, 34](#sources); [MP15, pp. 9–14](#sources).

## 2. Analysis needed for the sample

### Scope and notation

The candidate core is regular **affirmative indicative** forms of native verbs, with noun pairs 1/2, 3/4, 5/6, and 7/8. Class 9/10 can supply a small comparison set of nouns with the same singular and plural surface form, provided the final data supports each noun's class. The later worker should select the actual stem inventory from the sourced data folder and remove unsupported patterns from this candidate inventory. A hyphen marks a morpheme boundary, `C` a consonant, `V` a vowel, and `Ø` the absence of a pronounced prefix. A class number is a grammatical feature, not the spelling of an affix. [TS01, ch. 4](#sources); [FW26](#sources).

### Nouns: stem, class pair, and prefix slot

In FieldWorks, create **Noun** stem entries whose Lexeme Form is the stem alone, with a citation form for the dictionary headword. Give each stem its licensed singular/plural class pair as inflection features. The noun affix template has one **noun-class prefix slot before STEM**; that slot is obligatory for the overt-prefix paradigms below. Its affix entries carry a specific class feature, and same-spelled prefixes belonging to different classes remain distinct grammatical entries or senses. The official FieldWorks Bantu guidance recommends the stem-only Lexeme Form, Bantu singular/plural features, and a noun-class slot for parsing. [FW26](#sources).

| Pair | Singular noun prefix | Plural noun prefix | Analysis and constraint |
| --- | --- | --- | --- |
| 1/2 | `m-` (also `mw-` in some nouns) | `wa-` | People: e.g., `m-tu / wa-tu`. Do not derive every `mw-` noun from one unchanged stem without checking its pair. |
| 3/4 | `m-` (also `mw-` in some nouns) | `mi-` | E.g., `m-ti / mi-ti`. The `m-` of class 3 is homophonous with class 1 but carries a different feature and triggers different verb agreement. |
| 5/6 | `ji-` for a lexical set; no overt prefix for many other singulars | `ma-` | E.g., `ji-cho / ma-cho` “eye/eyes” and `gari / ma-gari` “car/cars.” Treat overt `ji-` versus no overt prefix as lexically selected, not a free choice on every stem. |
| 7/8 | `ki-`, with `ch-` for a lexical subset | `vi-`, with `vy-` for the matching subset | E.g., `ki-tabu / vi-tabu` and `ch-umba / vy-umba` “room/rooms.” The `ch-/vy-` pair occurs with some vowel-initial bases, but a following vowel alone does **not** select it: `ki-oo / vi-oo` “mirror/mirrors” preserves `ki-/vi-`. |
| 9/10, if included | no productive segment in the selected invariant nouns | same surface noun form | E.g., `safari/safari` “journey/journeys.” Store the two grammatical class values on the entry; do not make an unrestricted zero affix that licenses any bare string as either class. |

The noun pairs and class-5 variation are described in [TS01, pp. 33–39](#sources) and [MP15, p. 9](#sources). The class-7/8 contrast, including `kioo/vioo` beside `chakula/vyakula`, is explicit in [WW22, pp. 178–179](#sources). Some animate nouns outside formal classes 1/2 take human agreement, so written prefix alone is not a safe class classifier; keep such lexemes out of the core unless their agreement is deliberately represented. [TS01, pp. 33–39](#sources).

### Verbs: one fixed affix template

For this restricted construction, author the FieldWorks **Verb** template as `SUBJECT – TENSE/ASPECT – (OBJECT) – STEM – FINAL VOWEL`. Subject, tense/aspect, stem, and final vowel must be present in a finite affirmative indicative word in this sample; the object slot is optional and is licensed by a transitive stem and the intended reading. It is an ordinary **prefix slot immediately before the stem**, although some traditional accounts call the object marker an “infix” because it falls inside the written verb word. It is not a segment inserted inside the lexical root. Broader Swahili has negative and relative markers, extensions after the root, and post-final material; [NN18, §3](#sources) gives the larger order. The restricted order and a direct `tu-na-wa-on-a` versus `wa-na-tu-on-a` contrast are documented by [MP15, p. 13](#sources). [DH, §2.1](#sources) independently identifies the final vowel as the rightmost mood position.

| Noun class | Subject prefix | Object prefix | Feature to assign on an affix entry |
| --- | --- | --- | --- |
| 1 | `a-` | `-m-` before C; `-mw-` or `-mu-` before V | class 1, singular human |
| 2 | `wa-` | `-wa-` | class 2, plural human |
| 3 | `u-` | `-u-` | class 3 singular |
| 4 | `i-` | `-i-` | class 4 plural |
| 5 | `li-` | `-li-` | class 5 singular |
| 6 | `ya-` | `-ya-` | class 6 plural |
| 7 | `ki-` | `-ki-` | class 7 singular, **including nouns with `ch-`** |
| 8 | `vi-` | `-vi-` | class 8 plural, **including nouns with `vy-`** |
| 9/10, if included | `i-` / `zi-` | `-i-` / `-zi-` | class 9 singular / class 10 plural |

The table is the class-specific series in [TS01, chs. 20 and 34](#sources), with the crucial `ch-/vy-` noun versus `ki-/vi-` verb contrast also shown in [WW22, p. 179](#sources). Do **not** share a single `m-` affix entry between classes 1 and 3, or a single `i-` entry between classes 4 and 9: a surface homograph can carry different feature structures. Subject and object markers also occupy different slots even where their spelling is identical. [FW26](#sources).

If person rather than a classed noun supplies an argument, the small personal series needed for a later dataset is subject `ni-` “I,” `u-` “you (singular),” `a-` “he/she,” `tu-` “we,” `m-/mu-` “you (plural),” `wa-` “they”; object `-ni-` “me,” `-ku-` “you (singular),” `-m-/-mw-/-mu-` “him/her,” `-tu-` “us,” `-wa-` “them.” The sample need not use every person, and a same-spelled personal marker and noun-class marker must have their own feature values. A human object usually takes an object marker; with an inanimate object it may be omitted. This is a tendency in the real grammar, not a rule that every syntactic object must be marked. [MP15, pp. 13–14](#sources); [MM03, pp. 75–76](#sources); [TS01, pp. 244–247](#sources).

The candidate tense/aspect fillers are `-na-` present (also usable for a current ongoing event), `-li-` past, `-ta-` future, and `-me-` perfect. Keep them mutually exclusive in the sample's single tense/aspect slot. For regular native verbs, store the lexical root without the final vowel, e.g., `-som-` “read” plus the affirmative indicative final vowel `-a`: `ni-na-som-a`. The final vowel is a separate suffix slot, not part of every verb stem. [MP15, pp. 11–12](#sources); [TS01, chs. 21–29](#sources); [NN18, §3](#sources). Real Swahili also has subjunctive `-e` and present-negative `-i`; these need other constructions and must not be treated as free variants of `-a`. [DH, §2.1](#sources).

### Allomorph environments and phonology

For the chosen orthographic forms, prefer **restricted affix allomorphs** over a language-wide spelling rule. Set up a vowel natural class `{a, e, i, o, u}` and its complement consonant class. Class-1 object `-m-` is selected before a consonant-initial root; `-mw-` before a vowel-initial root in the sample's chosen standard spellings. The real language also allows `-mu-` before a vowel, with speaker and vowel effects, so `-mw-` is not the only real output. [MP15, p. 14](#sources); [MM03, p. 76](#sources). A FieldWorks allomorph can have a phonological environment over a natural class, and affix feature or inflection-class restrictions can narrow its use. [FW-Model, pp. 43–44](#sources).

For class 7/8 nouns, assign the `ch-/vy-` allomorphs only to the listed contraction subclass **and** before its vowel-initial bases; keep `ki-/vi-` for the regular subclass, including vowel-initial items such as `kioo/vioo`. A global `ki → ch / _V` or `vi → vy / _V` rule would incorrectly change those forms. [WW22, pp. 178–179](#sources); [MM03, p. 109](#sources). If an implementer chooses phonological rules rather than lexical allomorphs, lexical subclass selection must constrain the rule before vowel contact is evaluated. Within the proposed allomorph implementation, there are no further productive phonological rules and therefore no competing rule order to resolve. Do not add an infix-position environment or reduplication pattern: neither is needed for these Swahili features. The later Philippine sample is the one assigned infixation and reduplication. [The sample plan, §4](../../superpowers/plans/2026-09-26-site-home-learn-samples-plan.md).

Finally, the word parser can test that a *verb word* has a class-marked subject or object slot, but it does not by itself prove that the marker agrees with a separate noun elsewhere in a sentence. Keep the noun's class feature and the verb marker's class feature explicit for analysis and lesson explanations; assess whole-sentence agreement against sourced example sentences or a human-approved analysis. This is an inference from FieldWorks' word-grammar and affix-template model, not a claim that its morphological parser checks syntax. [FW-Model, §5](#sources); [FW26](#sources).

## 4. Realistic FieldWorks modelling mistakes

These are **proposed teaching errors**, not measured PanGloss output. “Parser reason” describes the expected morphological failure path; the exact trace text and each target word must be verified when the synthetic project and data rows exist.

| Mistake in the authored grammar | Words affected | Expected parser reason |
| --- | --- | --- |
| Put the noun-class slot after `STEM`, or assign the `ki-/vi-` noun affixes to a verb slot. | `kitabu`, `vitabu` “book/books” | With noun stem `-tabu`, there is no legal noun-prefix-before-stem path. A suffix-slot template expects the class marker after the stem, so the observed words fail or only a wrongly entered whole-word stem masks the mistake. [TS01, p. 37](#sources); [FW26](#sources). |
| Enter only `ki-/vi-` as class-7/8 noun allomorphs, omitting the lexically licensed `ch-/vy-` pair. | `chakula`, `vyakula` “food/foods” (while `kitabu/vitabu` still work) | After the noun prefix slot, no allomorph matches the initial `ch-/vy-`; the remaining stem cannot complete an analysis. Adding a global vowel rule would overgenerate `kioo/vioo`. [WW22, pp. 178–179](#sources). |
| Swap the tense/aspect and object slots in the verb template. | `tunawaona` “we see them,” `wanatuona` “they see us” | The attested order is subject–`na`–object–root–`a`. A template demanding object before `na` cannot assign the observed sequence to those slots. [MP15, p. 13](#sources). |
| Restrict verb `ki-` subject/object agreement to class 8, or substitute the noun's `ch-` allomorph for it. | `Chuo kimefungwa` “the university is closed”; also `anakipenda` “he/she likes it (class 7)” | The class-7 `ki-` marker is barred from its own verb slot; `ch-` is a noun allomorph here and does not supply the required verb agreement. The word may fail feature unification or lack a matching affix. [WW22, p. 179](#sources); [TS01, ch. 34](#sources). |

**Slow mistake:** let every noun take an unconstrained `Ø` class-5 prefix and an unconstrained `Ø` class-9/10 prefix, perhaps with optional copies of the noun-class slot. Then a bare stem such as `gari` or `safari` can start several otherwise identical analyses before its real class is known. Independent optional or empty choices multiply the candidate paths (two such binary choices already permit up to four paths; four permit up to sixteen), even when the surface word is unchanged. That is a **branching prediction**, not a measured speed ratio or a documented PanGloss algorithm. The repair is to confine no-prefix class-5 nouns and invariant 9/10 nouns to licensed stems/features, with one noun-class decision per path; verify the effect with a PanGloss Assessment work measure. [TS01, ch. 4](#sources); [FW26](#sources); [FW-Model, §5](#sources).

## 5. Recommended teaching simplifications

Each item is a **departure from real Swahili**, not a generalization about it.

1. **Use four productive-looking noun pairs in the core.** Real Swahili has additional classes and pairings, including 9/10 and 11/10, mass nouns, and animate agreement across formal class boundaries. Add a few 9/10 items only if the sourced data demonstrates the invariant form and `i-/zi-` agreement. [TS01, ch. 4](#sources).
2. **Choose a small, lexically controlled allomorph inventory.** Model `ji-/Ø` in class 5 and `ki-/ch-`, `vi-/vy-` in 7/8 only for sourced entries. Real singular/plural pairs and vowel-contact patterns have more lexical exceptions than a classroom paradigm suggests; a blanket vowel rule is demonstrably false. [TS01, ch. 4](#sources); [WW22, pp. 178–179](#sources).
3. **Use affirmative indicative native `-a` verbs and four common tense/aspect markers.** Real Swahili has negative, subjunctive, relative, habitual, imperative, derived, and borrowed-verb patterns. The final vowel is not universally `-a`, and some short verbs need special `ku-` behavior. [DH, §2.1](#sources); [NN18, §3](#sources); [TS01, chs. 21–29](#sources).
4. **Choose one written class-1 object variant before vowel-initial roots for each taught word.** The proposed sample uses `-mw-` where its source row supports that spelling. Real usage also permits `-mu-` in this environment; the sample must not present its choice as the sole grammatical Swahili form. [MP15, p. 14](#sources).
5. **Keep clause-level agreement as lesson evidence rather than pretend the word parser enforces it.** Real Swahili agreement relates a noun to markers on other words. A FieldWorks word template establishes the possible internal marker sequence and features; sample sentences and approved analyses convey the cross-word relation. [TS01, ch. 20](#sources); [FW-Model, §5](#sources).
