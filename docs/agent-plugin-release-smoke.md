# Agent plugin release smoke test

CI checks the packaged plugin folder, both marketplace manifests, the version match, and the required files in `motif-plugin.zip` through `test-package-stage.ps1`. The MCP tests check the bundled tool names and the skill layout. The client checks below need installed assistant applications and stay manual.

For each row, record the Motif version, OS, date, and result. Use a fresh user profile or restore the assistant configuration after the run.

| Client | Clean install and skills | Connect and workflow | Update and uninstall |
| --- | --- | --- | --- |
| Claude Desktop on Windows, macOS, and Linux | Install Motif. Before connecting, confirm its MCP configuration is unchanged. Enable Advanced AI mode, select Claude Desktop, and connect. Confirm the MCP entry invokes the installed Motif command with `mcp`; upload `motif-plugin.zip` from the opened folder through **Customize → Plugins**. Confirm the plugin's skills appear after restarting Claude Desktop. | Start a new chat and confirm the Motif tools are available. Follow the Motif workflow skill against a disposable project through Dry Run, Trial, revision, and Finalize. Confirm the workflow stops before Apply. | Install a newer Motif release and confirm the configured command still resolves. Upload the new ZIP through **Customize → Plugins** and confirm the skills update. Uninstall Motif and confirm its matching MCP entry is removed while other entries remain. Remove the uploaded plugin from Claude Desktop separately if it should no longer be available to that account. |
| Claude Code | Install Motif. Before connecting, confirm Claude Code has no Motif marketplace/plugin entry. Enable Advanced AI mode, select Claude Code, and connect. Confirm the local Motif marketplace and plugin are installed at user scope and the workflow and expertise skills appear in a new session. | Confirm the MCP tool names are available. Follow the Motif workflow against a disposable project through Dry Run, Trial, revision, and Finalize. Confirm the workflow stops before Apply. | Install a newer Motif release and start Motif so its update hook refreshes the local package and installed plugin. For the standalone skill installer, point it at the plugin directory: `npx skills add ./plugin --list`. The plugin root contains the expected `skills/<name>/SKILL.md` layout. Running the installer against the repository root does not rely on `plugin/skills` as a standard discovery root. The official Skills CLI documents `skills/` as a discovery container and accepts a local path; the Codex plugin instructions likewise define `skills/<name>/SKILL.md` under the plugin root.
