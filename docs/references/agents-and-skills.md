# Agents and expert skills

The FieldWorks expert answers model and interface questions; the parsing expert explains parser setup, failures and performance; the linguistic consultant supplies linguistic judgement and reviews whether a workflow meets a person's needs. These roles complement each other and should cite sources rather than imply that a model field alone proves parser behavior.

The 2026-09-09 source study distinguished lookup, diagnostic procedure and judgement. The 2026-10-03 surface inventory found a gap between reading or editing existing grammar objects and authoring a grammar from scratch. Its then-current counts and tool list are a historical inventory, not a statement of today's command catalog. Agent changes go through Proposals; a long-running job returns a handle for later observation. ADR 0009 describes the current agent boundary.
