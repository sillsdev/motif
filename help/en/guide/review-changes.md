# Review changes

**Review changes** gathers the analysis changes you have collected from other pages, grouped by what they do. For each word, it shows its analysis, the staged change, and whether the change still fits the current FieldWorks project. Reading this page does not apply anything.

1. Check each listed word and change. Choose **Undo** beside a change you no longer want, or **Undo all** to take back a whole group.
2. Choose **Check these changes** to measure the words you touched and see **What applying does to the numbers**. If the check is still running, you can choose **Cancel**.
3. Read what blocks Apply. The top of the page says how many things block it, and the Apply card lists each one with the action that clears it. Apply only when the changes still fit, the numbers are current, the evidence is complete, FieldWorks is not holding the project open, and no approved analysis would be lost.
4. Choose **Apply to FieldWorks project**. After a successful Apply, the page shows a receipt. There is no extra confirmation step.

If a change says **No longer fits**, Apply stays blocked. Remove that change or refresh the project and check it again. A change that no longer fits cannot be forced. See **When a change no longer fits** for steps to recheck it.

If a change is **Uncertain**, its sentence changed in FieldWorks after you made it. The page shows the sentence as it reads now. Choose **Check again** to keep the change, or **Undo** to take it back.

If Motif could not confirm an Apply, the page says that FieldWorks may already have these changes. Choose **Refresh** to check what the project holds now. Apply stays blocked until you do.
