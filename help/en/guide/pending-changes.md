# Pending changes

Pending changes are the analysis choices you have collected in Motif but have not yet written to FieldWorks. They can come from **Texts** and are listed together on **Review changes**. The window labels them as “changes not applied yet.”

Use **Remove** to withdraw a choice, or return to **Texts** to make a different choice for the same word and analysis. The list belongs to its project and remains available if you close Motif and open that project again.

Nothing is written to FieldWorks while you are collecting or reading these changes. Before applying, use **Check these changes** to measure the touched words, confirm that the evidence is current and complete, and make sure every choice still fits. Then choose **Apply to FieldWorks project** while FieldWorks is closed.

This page describes the window’s “changes not applied yet” wording. The related stored-change concept is linked here as [pending changes](term:proposal).
