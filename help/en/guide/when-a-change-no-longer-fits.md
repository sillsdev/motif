# When a change no longer fits

**No longer fits** means FieldWorks changed something the pending analysis choice was made against. For example, the word form may have changed or the analysis it referred to may no longer be present. It is different from old Overview numbers: this message is about whether a particular change can still be applied safely.

1. Open **Review changes** and read the reason beside the affected word.
2. If you want to keep trying the change, save the project in FieldWorks, then choose **Refresh** in Motif.
3. On Review changes, choose **Check again against the refreshed project** if it is available. Motif checks whether the original identities still fit.
4. If it still says **No longer fits**, choose **Remove the ones that no longer fit** or remove that change individually. Return to **Texts** and make a new choice against the current project.

Apply remains blocked while any change no longer fits. Do not treat **--force** or another override as a way to apply it; the window does not provide such an override.
