## Mechanism

Literal root forms can use a trie-like spelling lookup, while pattern-shaped root allomorphs may require scanning and pattern matching across many entries. An expressive pattern is not free lexicon indexing.

## Check and repair hypothesis

Separate load time from lookup time. Use literal alternatives when they express the same finite generalization; keep patterns when needed and benchmark representative words.

Record completed confirmed analyses, candidate/search counts, per-word time and caps on the same
content and machine. A budget exhaustion is inconclusive. Retain every required analysis–surface
pair; see [measurement procedure](../workflow/measuring.md).
