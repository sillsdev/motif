	<h3>Works with the AI you already use</h3>
	<p>Give an agent a machine-readable description of Motif, or prepare a reviewable Handoff to share with a chat model.</p>
	<ul>
		<li><code>motif help --all --json</code> — the command catalog and help text.</li>
		<li><code>motif handoff &lt;project.fwdata&gt; --out &lt;folder&gt; --invocation &lt;id&gt; --json</code> — a Handoff with retained parse evidence.</li>
		<li><code>motif handoff &lt;project.fwdata&gt; --out &lt;folder&gt; --no-assess --json</code> — a Baseline-only Handoff.</li>
	</ul>
	<p>Read the full agent guide at <a href="/llms.txt">/llms.txt</a>.</p>
