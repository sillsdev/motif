# Sources

Open **Texts**, then its **Sources** side panel. A Source names external material; its **Context** is the books and chapters the project works on. **Current Chapter** records where you are working on this machine, including a chapter outside that Context. The folder on this machine and Current stay local.

The window reads Paratext Source names, saved Context and local settings. Select a Source to inspect these facts. **Stage Context in Proposal** proposes a change; it does not change the saved Context until you review and Apply the Proposal. **Add Paratext Source** also stages a Proposal. Enter the Source ID, name, versification and chapter range; an optional folder is saved locally when the Source is staged.

External Passage text is unavailable through this reader. Paratext text is never imported into the FieldWorks project. The window does not offer .txt or JSONL Source ingestion, because the Source command contract does not support those kinds.

Choose **FieldWorks Texts** to return to the available Text reader. Check Texts for the current Selection and choose a Text in Passage to read its stored analyses. FieldWorks Text selection is separate from the external Source Context. An existing Corpus is not treated as a Source.

Removed, unreadable and outdated Sources are shown as such. Refresh the project to read a newer Baseline. No missing count is shown as zero, and opening Sources never starts a parse.

Source changes use the pending Proposal. If another Proposal is the current staging target, choose **Return to Current Project** before staging a Source change. Folder and Current remain local commands.
