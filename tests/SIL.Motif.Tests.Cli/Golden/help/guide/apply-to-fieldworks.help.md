# Apply to FieldWorks

In **Proposals**, open the Proposal you want to apply and read its proposed changes, Rationale and evidence. Complete **Before you apply**, then choose **Apply…**. Motif activates that Proposal, reads its current review and checks whether Apply is available. Before you confirm, the question names the backup: Motif does not back up your project, so back it up in FieldWorks first (**How to Back Up a Project in FieldWorks** opens FieldWorks' own help). Confirm **Apply** only when you want those changes written to FieldWorks.

Every change must still fit. The project's evidence and the Proposal's Trial must be current and complete enough for the engine's readiness rules. A held FieldWorks project, lost approved analysis, dropped grammar or an unresolved previous Apply can prevent writing. **Apply…** stays off until the Proposal has a current Trial, a Difference from that try and a Dry Run recorded for the Proposal. The checklist shows the actions to take on the Proposal document. Use **Refresh** if FieldWorks changed. Choose **Try Again** when the Trial is outdated and **Run Dry Run** when the checklist asks for it. Follow any additional guidance beside Apply. The window does not offer a force action.

A successful Apply shows the real Receipt. It makes the evidence of other open Proposals outdated, so measure them again before deciding. After an unconfirmed write, FieldWorks may already have these changes. Check the project and choose **Refresh** before trying Apply again. The window provides no post-Apply Undo; staged-change Undo applies only before changes have been applied.
