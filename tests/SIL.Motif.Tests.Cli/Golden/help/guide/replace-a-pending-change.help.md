# Replace a Pending Change

Return to the word in **Texts**. Press Ctrl+Z (⌘+Z on macOS) to take back the last staged choice, or stage the new choice for the same place. There is no on-screen Undo button, and Ctrl+Z takes back only the most recent staging action. Read the word's current context before making another choice. **Undo** affects staging only and does not reverse an applied Proposal.

After replacing a staged change, measure the exact new content again before applying. Earlier evidence does not establish readiness for the replacement. Read [Pending Changes](guide:pending-changes) and [Apply to FieldWorks](guide:apply-to-fieldworks).
