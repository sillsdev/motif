# Connect an assistant

Claude is not in Motif's window. The window has no Ask Claude, no Assistant Connections and no API key. You work with Claude only through the MCP in Claude Desktop, where Claude can use Motif's project tools. The assistant still cannot Apply a Proposal; a person reviews and Applies it in Motif.

For Claude Desktop, add `motif mcp` to Claude's MCP configuration, upload the Motif plugin ZIP (`motif-plugin.zip`) in **Customize → Plugins**, and restart Claude Desktop. Upload the latest ZIP again after a Motif update to refresh the skills saved to your Claude account.

Changing the setup affects new Claude sessions. Restart Claude Desktop to apply it to a session that is already open.

Name a word, warning, Proposal or Grammar Guide section to Claude and it records a Request. Configuring Claude does not prove a live Claude connection. ChatGPT connection status belongs to its own tunnel only. See [Working with Claude](guide:ask-claude).
