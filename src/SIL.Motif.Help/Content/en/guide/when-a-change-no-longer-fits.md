# When a Change No Longer Fits

A staged change names the project content it was made against. A later FieldWorks save can leave that change unable to fit, or leave its occurrence uncertain. Apply stays unavailable until the engine can establish that the changes fit.

**Refresh** to read the current project, then inspect the affected word in **Texts**. **Undo** a staged choice that is no longer wanted, or check it against the current context before staging a replacement. Motif never forces an uncertain change onto a different place. See [Replace a Pending Change](guide:replace-a-pending-change).
