# When a change no longer fits

When a pending change is in the **No longer fits** group, use these steps to check the original choice against the current project.

1. Open **Review changes**. Changes that no longer fit are in the **No longer fits** group at the top of the page. Select one to read what changed in FieldWorks in the Inspector. If the Inspector is closed, choose **Details** from the change's **⋯** menu.
2. If you want to keep trying the change, save the project in FieldWorks, then choose **Refresh** in Motif.
3. In the **No longer fits** group, choose **Check again**. Motif checks whether the original identities still fit.
4. If it still says **No longer fits**, choose **Undo all** beside that group, or choose **Undo** beside one change. Return to **Texts** and make a new choice against the current project.

Apply remains blocked while any change no longer fits. The window does not offer a way to force a change that no longer fits.
