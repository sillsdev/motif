# Warnings

**Warnings** shows findings from a check of the whole grammar. They are stored for the [Baseline](term:baseline), and do not depend on which texts or words you selected. PanGloss may include an explanation or guidance with each finding.

If the grammar has not been checked for this Baseline, choose **Check the grammar again**. PanGloss reads the whole grammar, so a check can take a minute for a large project. **Refresh** captures a new Baseline and checks the grammar again. Later visits show the stored findings; opening the page does not start a check.

The filter chips count findings by report level. Identical findings with no named item share one row, with the repeated count beside the title. **Touch your words** shows the number of distinct Selection words matched to named FieldWorks items, when that count is available. Turn it on to show only findings with those matches. The **Sort** menu orders the rows by that same count or by the order in the report.

A finding may have exact word uses, words reached only by membership or spelling, or no word list. Membership and spelling remain labelled because neither confirms an exact use of the named item. **None of your words** means PanGloss named an item but no Selection word matched it. When a word count cannot be established, Motif leaves it unavailable instead of showing zero. If PanGloss names no item, the row says so.

Open a row to read PanGloss's full description and any explanation or guidance it supplied. **What to do in FieldWorks** appears only when PanGloss supplied guidance. The named item opens in FieldWorks only when PanGloss supplied a verified destination. If a finding no longer appears after **Refresh**, its row says **Gone after Refresh**. Save edits in FieldWorks, refresh Motif, then parse the affected words again to see their current results.

![Grammar findings saved for the current Baseline](shot:warnings-filter/findings)

PanGloss supplies each finding's title, description, explanation and guidance in the report's recorded language. **Learn more** opens its reference when available. Motif displays that text without adding advice of its own.

A missing or unresolved subject has no object link. A project setting has no individual object to open. A named live object opens only through the destination PanGloss supplied; Motif does not infer a destination from the finding's sentence.
