# Warnings

**Warnings** shows findings from a check of the whole grammar. They are stored for the [Baseline](term:baseline), and do not depend on which texts or words you selected. Each finding uses PanGloss's explanation and guidance; error-level findings can identify grammar problems that prevent parsing.

If the grammar has not been checked for this Baseline, choose **Check the grammar again**. PanGloss reads the whole grammar, so a check can take a minute for a large project. **Refresh** captures a new Baseline and checks the grammar again. Later visits show the stored findings; opening the page does not start a check.

Each finding uses the title, explanation and guidance PanGloss supplied. Open a row to see the verified FieldWorks places PanGloss supplied, its named subjects, the words the stored evidence can connect to it, and a Handoff for that finding. Spelling matches are labelled because a matching letter does not prove the parser used that phoneme. Some findings have no word attribution. If a finding no longer appears after Refresh, its row says **Gone after Refresh**. Save edits in FieldWorks before Refresh, then parse the affected words again when you want to see their current results.

![Filtered grammar findings](shot:warnings-filter/filtered-findings)

PanGloss supplies each finding's title, explanation and guidance in the report's recorded language. **Learn more** shows its background when available, and **PanGloss reference** opens the documentation for the supported parser release. FieldWorks places come from the report's verified destinations, independently of how the guidance is worded. Motif adds no advice text.

A missing reference is shown as unavailable and cannot open FieldWorks. A project setting stays a setting, with no individual object link. A named live object opens only through the destination PanGloss supplied. None of these states is inferred from the warning's sentence.
