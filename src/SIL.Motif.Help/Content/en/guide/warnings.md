# Warnings

**Warnings** shows findings from a check of the whole grammar and allomorph refusals recorded by **Parse all words** for the current [Baseline](term:baseline) and **Selection**. Findings from the parse are labelled **Parse all words** and retain the parser's refusal reason. The grammar check and the parse can report different findings. PanGloss may include an explanation or guidance with each finding.

PanGloss reports an unreadable phonological environment as a warning. Roots ignore that restriction but keep valid ones; ordinary affixes add an unrestricted pass beside valid passes; an infix with no valid position is skipped.

If the grammar has not been checked for this Baseline, choose **Check the grammar again**. PanGloss reads the whole grammar, so a check can take a minute for a large project. **Refresh** captures a new Baseline and checks the grammar again. Later visits show the stored findings; opening the page does not start a check.

The filter chips count findings by report level. The table has one row per kind. Motif groups the rows by area, a guess from the finding's code and the kinds of FieldWorks item it names: Environments, Phonological rules, Affixes, or otherwise Other findings. The areas keep that fixed order. Each row shows severity, item, problem text and named words; the area heading shows its total finding count. The named words column shows an exact count, **none** when the finding says no Selection word uses the named item, or **—** when an exact count is unavailable. Choose **Details** or press Enter on a selected row to read each finding. The **⋯** menu has the same details action and any available follow-up actions. **Touch your words** shows the distinct Selection words matched to named FieldWorks items, when available. Turn it on to show only kinds with those matches. The **Sort** menu orders the rows inside each area by that same count or by the order in the report; it does not reorder the areas.

A finding may have exact word uses, words reached only by membership or spelling, or no word list. Exact uses include analyses held in FieldWorks and analyses the parser returned, including words typed into setup with no Texts. If a word has no analysis, a named allomorph or entry can reach it through a **spelling match**: the word contains the form's spelling. This does not confirm use of that item. Membership and spelling remain labelled because neither confirms an exact use of the named item. **None of your words** means PanGloss named an item but no Selection word has a confirmed identity use. Choose **Details** on the row to see any separately labelled membership or spelling matches. Spelling matches show their distinct word count. When a word count cannot be established, Motif leaves it unavailable instead of showing zero. If Motif cannot follow every named connection, Details retains confirmed words but the table leaves the full count unavailable. If PanGloss names no item, the row says so.

Choose **Details** on a row to read each finding's explanation, **What to do in FieldWorks** guidance, named subjects, and exact parser message. When PanGloss supplied no guidance, the row says **PanGloss gives no advice for this kind yet**. A named entry with a verified destination has an **Open … in Lexicon Edit ↗** link; other subjects open only through the verified destination PanGloss supplied. If a kind no longer appears after **Refresh**, its row says **Gone after Refresh**. Save edits in FieldWorks, refresh Motif, then parse the affected words again to see their current results.

PanGloss supplies each finding's title, description, explanation and guidance in the report's recorded language. **Learn more** opens its reference when available. Motif displays that text without adding advice of its own.

A missing or unresolved subject has no object link. A project setting has no individual object to open. A named live object opens only through the destination PanGloss supplied; Motif does not infer a destination from the finding's sentence.
