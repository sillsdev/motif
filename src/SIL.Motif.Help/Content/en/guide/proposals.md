# Proposals

**Proposals** lists every set of changes you can review: the Proposals an AI assistant put together, and the changes you collected yourself that are not applied yet. Its table shows who built each one, its status and, when it has a Trial, four measures from before and after.

Use the filters to see three groups:

- **Your changes not applied yet** are the changes you collected on **Texts**; they are also listed on **Review changes**.
- **Waiting for you** includes Proposals with a current Trial, Proposals that need another try, and Proposals that have not been tried. Choose **Try it** or **Try again** to measure one on a copy of the project; nothing re-runs until you ask.
- **Closed** lists Proposals that were applied, declined, superseded or withdrawn. Select **Closed** to see those Proposals. When closed Proposals exist, **Show closed** includes them with the other groups and clears the current filter; **Hide closed** hides them and clears the filter.

At wide widths, each row shows the Proposal's name and number of changes. At narrow widths, the table keeps the name, status and actions; choose **Details** from the row's **⋯** menu to read its counts and other facts in the Inspector. Its measures are approved words kept, Text Coverage, warnings and **Work**, the parser work in work steps, with today's value beside the value from the last try. **Work** is blank (a dash) when the Trial cannot be compared with today's parse, for example when a search was stopped. The Inspector adds **Time on this computer**, which changes with how busy the computer is and so is only a second figure. A number that moved is shown in bold. When there is no Trial, the table says **Not tried yet**. A chip can say that approved words were lost, that a change no longer fits, or that another Proposal also changes some of the same words. A Proposal that only approves or removes analyses measures only the words it touches; every other word keeps today's value, so its totals still compare with today's.

Select a row to choose the Proposal's details. When the Inspector is collapsed, choose **Details** from the row's **⋯** menu to reveal them. The Inspector shows its status, who built it, a summary of its changes and the numbers from its last try. Choose **Open in Review changes** there to review the Proposal. Choose **Open** on a row to see the project's pages with the Proposal beside today: the numbers on **Overview**, **Texts**, **Timing** and **Warnings** show today's value and the Proposal's. The copy used for a Trial is thrown away; your FieldWorks project is not changed.

Below those numbers the Inspector shows a **Difference** section for every Proposal you select that is not a draft. A Difference compares what the Proposal's last try built with the Approved analyses saved in FieldWorks, for one Text. It is advice only: it never changes the project and never applies anything. Choose a Text, then choose **Make Difference**. It is never made for you after a try, because it can take a while. A bar shows how many words are compared, and **Cancel** stops it; a cancelled run saves nothing. When it is ready the section shows how many words to check and how many improved, with chips that list those words and, for one word, where it occurs in the Text. A Proposal keeps one Difference for each Text and each set of decisions it was compared with, so several sit side by side: making one for another Text replaces nothing. When there is more than one, a **Saved Differences** list switches between them, and every Difference says which Text it compares and whether it was read against the Approved analyses people saved in FieldWorks or against a program's decisions. **Make Difference** always compares with people's decisions, and the same button reads **Make Difference Again** when the Proposal already has one for the chosen Text; it replaces only that one. A Proposal that was never tried shows a note asking you to try it first, with no button. Once a Proposal is decided, only the Difference's summary is kept, the section says so, and a new one cannot be made. A deferred Proposal also keeps only the summary, and its words are not shown; the section says so and **Make Difference Again** brings the words back until the Proposal's status next changes.

The status column says **Draft** for your changes and **Ready**, **Deferred**, **Applied**, **Declined**, **Superseded** or **Withdrawn** for other rows. A declined or withdrawn Proposal offers **Reopen**, which makes it a Draft again with its history kept. A declined, superseded or withdrawn Proposal offers **Delete**, which removes it and its tries. An applied Proposal cannot be deleted; it and its record of what was applied are kept. The **⋯** menu repeats each row's available actions.

The number beside **Proposals** in the sidebar counts Proposals whose Trial is current.
