# Pending Changes

Changes staged from a word stay pending until a person applies them. Open **Proposals** to inspect the pending document and its Comments and evidence. Staging does not write changes to FieldWorks.

**Undo** and **Redo** affect staged changes only. Before applying, check that the changes still fit the project and explicitly measure what they do. Missing or outdated evidence is not a successful check. See [Apply to FieldWorks](guide:apply-to-fieldworks) and [When a Change No Longer Fits](guide:when-a-change-no-longer-fits).
