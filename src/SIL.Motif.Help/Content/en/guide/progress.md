# Progress

**Progress** shows supported next actions for the current project. A Proposal appears here when its stored standing says it is waiting for a decision. When no supported action is available, the page leaves it out.

The health strip shows available project facts. Open its details for the recorded median parser work, when one exists, and to turn on Diagnostics. Opening this page or the health details does not start a parse. See [Progress and project health](guide:overview).
