# Try a Word

Use **Try a Word** to trace one word through the grammar. The word does not need to appear in a chosen text or exist in the FieldWorks project.

1. Enter a word in **Type any word...**.
2. Choose **Try it** and wait for the trace. Choose **Cancel** to interrupt a running search.
3. Read the result and any search limit. **Search incomplete** takes precedence even if the parser found an analysis; an unfinished search cannot establish that no analysis exists.
4. Read the result summary and analysis cards, then **Recorded trace**. Each summary groups analyses with proven equal morphology. **Recorded twice** counts source records; it does not establish two different derivations. Each card shows the recorded morpheme names even when PanGloss cannot match them to FieldWorks entries. Glosses appear when recorded; absent glosses are not inferred.
5. Select a recorded event to read its explanation. Plain translates recorded reason codes into sentences. Only a missing reason says **PanGloss didn't record why.** An unfamiliar code remains visible.

Choose **Plain** or **Expert** beside **Try it**. The filled control shows the selected view. The installed window remembers your choice. Switching keeps the same recorded attempt, selected event address and open inspector; it does not run the parser again. Addresses identify occurrences within this saved trace, not across newly generated traces.

**Plain** puts **Why it did not parse** and the attempts that got furthest above the trace. A sentence names a rule or required feature only when PanGloss recorded it; the small code remains visible. The building story starts with the recorded stem form, then forward affix and phonological steps, then the result. Additional events are counted at the end and remain in **Expert**. Selecting a separate recorded event keeps it visible without making it part of that attempt. **Tried** does not establish that an affix was built.

**Expert** keeps event names, subrule indices and input/output shapes in the parser's order, including both recorded passes. Missing input and output values appear blank; focus their tokens to learn that they were not recorded. A subrule appears only when the parser recorded a positive index. Choose **Show one analysis path** and turn off **Every step** to read its recorded ancestors and terminal event. **Showing every step** includes other search context; neighboring events alone never establish attempt membership or a cause. **Phonological rules applied** lists recorded phonological events in the chosen view, with each event's own outcome. **Tried** does not mean **Applied**, and an unchanged shape does not prove application. **Parser record** starts folded and keeps the exact source analyses, producer identifiers, projection details and unprojected morpheme names. FieldWorks morpheme forms appear only when their projections are available; parser names alone do not establish a FieldWorks analysis.

Select an event to read its sentence directly beneath the event row. The selected event's **Parser record** and rejection details start folded. The record preserves unknown producer fields and omits its children from this detail view; saving still keeps the whole diagnostic. Tokens explain themselves on hover or keyboard focus. **Environment notation** keeps the recorded diagnostic operand intact and shows **Authored environment notation unavailable**. Decoding requires the trace to explicitly identify authored environment text; the supported trace formats do not establish it. Strings, structured operands and punctuation such as `/`, `_`, `#`, brackets, parentheses and `?` cannot establish that language by themselves, so they remain raw.

**Reason not recorded**, **Rejection details not recorded**, **The grammar of this trace was not recorded**, and **FieldWorks word context unavailable** identify facts the page cannot establish. Missing word context does not mean the word is absent from FieldWorks. The recorded tree shows search context; neighboring events alone do not establish which rule caused an attempt to fail.

**FieldWorks beside the parser** shows every stored analysis for the returned word, whether the trace parsed it or not, with **Approved**, **Disapproved** or **Unknown** beside each analysis. Identical displayed analyses share one interlinear line with counts for each Opinion; this display grouping does not establish identity equality. Each piece shows a trace mark only when an event names its exact identity; otherwise it says **No step recorded**. The result line also names the recorded opinions. A completed parsed search shows **Same** or **Different** when recorded identities establish a comparison; otherwise it shows **Parsed** and the analysis count. A completed search that finds no analysis shows the same meaning as the Matrix, such as **Lost** for an Approved word. An unfinished search cannot establish that an Approved analysis was lost. Save and Baseline times use the computer's local time. **FieldWorks saved since** follows the same freshness evidence as the top bar. A word absent from that Baseline differs from a wordform with no stored analyses. Unknown membership and unavailable context remain explicit.

**No terminal attempt was recorded before the search stopped** marks an interrupted search without a terminal attempt. Its recorded progress remains available in the tree. Recorded terminal attempts show only their returned reasons and attribution. **Steps on this path** lists actual ancestors and the terminal event; **Recorded tree context** shows nearby events whose membership is not established. Event addresses identify repeated occurrences within this saved trace, and the small notation names the recorded pass and outcome.

An earlier parse's measured times appear in a separate block named by the word's recorded measurement time. The block stays hidden when that source time was not recorded. They cover that parse's whole search for the word, including stopped attempts. They are not times for a step in this trace. Shares use that measurement's word time; **Not attributed** and any timer overrun appear only when the measurement recorded them.

Hover over the result or use keyboard focus to reveal **Analyze texts**, **Timing**, and **AI Handoff**. **Analyze texts** opens the returned word in its text, where opinions are changed. These actions keep addressing the displayed result when you edit or clear the input for another Try. **AI Handoff** keeps this diagnostic and the Baseline recorded with it; it does not parse the word again or make a replacement trace. The menu beside **Try it** contains recent words and tools for copying, saving or opening a trace. **Copy for a chat model** includes the instructions, one-line summary, and original diagnostic JSON. **Full derivation** starts folded and provides all recorded steps and filters. Saving keeps the original diagnostic regardless of display filters.

Both views name the Baseline that actually produced the trace, using its capture time in the computer's local time. A trace without a recorded Baseline says so. When the earlier parse and the trace record different Baseline identities, the page says **This trace and the earlier parse used different Baselines. Refresh and try again.** That difference does not establish that a grammar change caused a failed search. Capture details keep the source project's save time as well. A Refresh published while a request waits can change which Baseline it uses. An older workspace description cannot relabel the returned evidence.

Recorded details can include the replacement lexical entry for a Blocked event, the template slots a branch applied or skipped, and the completion gate that ended a partial attempt. A completed lookup records how many possible roots it returned; those are not counts of successful analyses. Typed rejection details retain the operands PanGloss actually tested, including any authored environment identity and text. A phonological step with an unavailable reason remains unknown.

A Blocked event records an intermediate result. In the supported parser it means replacement by a compatible entry in the same lexical family; search can continue. Missing reasons, rejection details and grammar sources are shown as not recorded, and unfamiliar reason codes keep their raw notation.

The main analysis cards combine source records only when available projections establish equal ordered allomorph and grammatical information identities, including inflection type. Equal spellings alone do not establish that they are the same analysis. The recorded source list keeps every producer record.
