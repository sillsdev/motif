# Default Selection

The [Default Selection](term:default-selection) is the set of Texts and added words Motif measures when you run the project without choosing another Selection. Motif saves it with the project. Each [parse](term:parse-all-words) keeps the exact word list it measured, so changing the Default Selection does not rewrite earlier results.

The first time you set up a project, choose texts and add any extra words in **What should Motif measure every time?** Choose **Configure…** from the project menu to edit that choice later. The Selection needs at least one text or added word before Motif can parse.

The Default Selection is not a search query that changes behind your back. Motif resolves the chosen material for each run and records what it measured. Use **Refresh** when you want the saved project and its current Default Selection measured again.
