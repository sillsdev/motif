# Default Selection

The [Default Selection](term:default-selection) is the set of Texts and added words Motif measures when you run the project without choosing another Selection. Motif saves it with the project. Each [parse](term:parse-all-words) keeps the exact word list it measured, so changing the Default Selection does not rewrite earlier results.

The first time you set up a project, choose texts and add any extra words in **What should Motif measure every time?** Choose **Configure…** from the project menu to edit that choice later. The Selection needs at least one text or added word before Motif can parse. Setup, Settings, and **Analysis options** edit the same saved parsing policy; see [Settings](guide:settings) for its time-limit choices.

The Default Selection is not a search query that changes behind your back. Motif resolves the chosen material for each run and records what it measured. After saving in FieldWorks, press **Refresh** to read the saved project, then choose **Parse all words** to measure the current Default Selection again.
