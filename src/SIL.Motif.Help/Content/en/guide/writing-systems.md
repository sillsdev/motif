# Writing systems in the window

Motif uses the writing-system settings saved in the Baseline when it displays project language text. Text keeps its FieldWorks direction and style size in the window.

Most word forms, glosses and interlinear fields use the **Normal** style. A line in **Analyze texts** uses the source paragraph's style. If a requested font is missing, Motif uses an available fallback and shows one quiet notice the first time it draws text in that writing system.

In FieldWorks, change a writing system's font, font features or direction under **Format › Set up Vernacular Writing Systems…** or **Format › Set up Analysis Writing Systems…**. Choose the **Font** or **General** tab. Change style-specific fonts and sizes under **Format › Styles…**.

Capture a new [Baseline](term:baseline) after changing these settings so Motif reads the saved values. [Show writing systems](cmd:writing-systems) lists the values Motif recorded.
