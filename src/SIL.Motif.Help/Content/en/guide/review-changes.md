# Review changes

**Review changes** gathers the analysis changes you have collected from other pages. For each word, it shows the chosen action, the relevant analyses, and whether the change still fits the current FieldWorks project. Reading this page does not apply anything.

1. Check each listed word and action. Choose **Remove** beside a change you no longer want.
2. Choose **Check these changes** to measure the words you touched and see **What applying does to the numbers**. If the check is still running, you can choose **Cancel**.
3. Apply only when the changes still fit, the numbers are current, the evidence is complete, FieldWorks is not holding the project open, and no approved analysis would be lost.
4. Choose **Apply to FieldWorks project**. After a successful Apply, the page shows a receipt. There is no extra confirmation step.

If a change says **No longer fits**, Apply stays blocked. Remove that change or refresh the project and check it again. A change that no longer fits cannot be forced. See **When a change no longer fits** for steps to recheck it.
