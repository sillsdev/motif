# Ask the linguist when evidence runs out

Ask when two analyses fit the evidence and choosing between them changes the Proposal. A useful question lets the linguist distinguish those analyses using forms already in the project and one concrete prediction.

## Guess, ask or defer

- **Guess** only a low-impact, reversible choice that the existing evidence supports; keep it in a Draft and check it with a Dry Run and Trial.
- **Ask** when the linguist can answer a concrete contrast. Ask one question at a time and show the evidence plus the competing predictions.
- **Defer** when the project lacks the forms or the linguist cannot yet distinguish the choices. State what evidence would resolve the choice, and do not invent a Proposal.
- **Say the tool is missing** when Motif cannot create a required FieldWorks object. Explain the needed encoding and wait for a composer; do not imitate it with a different object.

When the project has no evidence for requested forms, do not suggest an affix shape, allomorph or example word, even as a prediction or an unapplied draft. Say what attested forms and contexts would resolve the question, then ask for them.

For example: “I can’t determine this pattern from the project. Could you share attested forms in the relevant contexts, including a contrasting form if available?”

## Build the question from evidence

Read forms with `motif_lexicon`, `motif_word` or `motif_texts`. Use the actual spellings and contexts returned for this project. Do not present guessed forms as attested; when requested forms are absent, ask for attested forms instead of predicting spellings.

Use this frame and replace every bracketed item with project evidence:

> “I found `<attested form A>` in `<observed context A>` and `<attested form B>` in `<observed context B>`. The two analyses predict `<candidate A>` versus `<candidate B>` for `<unobserved or contrasting context>`. Which form would a speaker use there?”

Ask for the missing fact only. Do not bundle a request to choose the analysis, name a rule, provide more examples and approve a Proposal into one question.
