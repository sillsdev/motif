# Applying changes

Apply writes the pending analysis changes to the FieldWorks project as one operation. Before starting, save your work in FieldWorks and close the project there; Motif blocks Apply while FieldWorks is holding it open.

1. Open **Review changes** and read every listed change.
2. Choose **Check these changes** and wait for the measurement to finish. Review the summary under **What applying does to the numbers**.
3. Confirm that each change still fits, the evidence is complete and current, and no approved analysis would be lost.
4. Choose **Apply to FieldWorks project**. Motif shows a receipt when it succeeds.

If Apply is unavailable, read the reason beside the button. A stale result needs **Refresh**; incomplete evidence needs another successful check; a change that says **No longer fits** must be removed or checked against a refreshed project. The window does not offer a way to force a change that no longer fits.
