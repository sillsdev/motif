# Apply to FieldWorks

In **Proposals**, open the Proposal you want to apply and read its Rationale and evidence. Choose **Apply…**. Motif activates that Proposal, reads its current review and checks whether Apply is available. Confirm **Apply** only when you want those changes written to FieldWorks.

Every change must still fit. The project's evidence and the Proposal's Trial must be current and complete enough for the engine's readiness rules. A held FieldWorks project, lost approved analysis, dropped grammar or an unresolved previous Apply can prevent writing. Read the reason beside Apply and use **Refresh** or **Try Again** as appropriate. The window does not offer a force action.

A successful Apply shows the real Receipt. It makes the evidence of other open Proposals outdated, so measure them again before deciding. After an unconfirmed write, FieldWorks may already have these changes. Check the project and choose **Refresh** before trying Apply again. The window provides no post-Apply Undo; staged-change Undo applies only before changes have been applied.
