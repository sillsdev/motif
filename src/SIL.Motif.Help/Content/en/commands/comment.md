# Comment on a Draft

Sets or replaces a Draft's rationale for its proposed changes. A comment preserves review context without changing the Draft's operations.

## Example

```text
motif comment --project <fwdata> --draft <name> "Why this change fits the language"
```

Use the comment to explain why the Draft's changes are appropriate. The comment is separate from its [label](cmd:label), which helps identify the Draft in lists. Only a person can Apply the resulting Proposal.
