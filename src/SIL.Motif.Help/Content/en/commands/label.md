# Label a Draft

Sets or replaces the short label that identifies a Draft in lists and review. A label does not change the Draft's operations.

## Example

```text
motif label --project <fwdata> --draft <name> "Add the plural form"
```

Use the label to recognize a Draft while reviewing it. It is separate from the Rationale written by [`proposal rationale`](cmd:proposal%20rationale). Only a person can Apply the resulting Proposal.
