# Record a speaker's answer

`hypothesis answer` records a speaker's answer to one question queued on a hypothesis.

## Example

```text
motif hypothesis answer H-12 --project <fwdata> --question 1 --answer yes
```

`--question` is the 1-based number in the hypothesis's question list.
