# Finalize a Proposal

Finalizes a Draft as an immutable Proposal revision for a person to review. Evidence for unchanged content on the same Baseline remains current.

The Draft must have both a short label and a Rationale before it can be finalized. If either is missing, set the label with `motif label` or the Rationale with [`proposal rationale`](cmd:proposal%20rationale), then retry Finalize.
