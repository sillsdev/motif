# Read grammar objects

`grammar read` reads one kind of authored project object from the current [Baseline](term:baseline). Choose `phoneme`, `natural_class`, `environment`, `part_of_speech`, `inflection_feature`, `lexical_entry`, `phonological_rule` or `affix_template` with `--kind`. A `phonological_rule` read returns rules in the order they apply, not sorted by name, each with its 1-based `position`, `id`, `disabled` flag, `rightHandSideCount` and `intent`, the whole intent that [Edit a sound rule](cmd:compose-edit-phonological-rule) copies into `expected`; read it with `--json`. To change the order of rules, use [Reorder sound rules](cmd:compose-order-phonological-rules) with the ids read here, in the order shown.

An `affix_template` read lists each inflectional template with its category, whether it is `final`, and its `prefixSlots` and `suffixSlots` in template order; each slot carries its `id`, `name`, `optional` flag and the `affixes` that fill it (entry id, headword, morph type, analysis id and part of speech). A `lexical_entry` read with `--id` also lists every analysis in `msas` with its kind, part of speech, `inflectionClass` for a stem and `slots` for an inflectional affix, so the morphotactic structure is readable without parsing the project file. `--query` and `--exact` match a template's name only, and an affix with no inflectional analysis, such as a variant, is not listed under any slot; `--morph-type` is refused for any kind but `lexical_entry`. Both page with `--cursor` (the `nextCursor` of the previous page) and `--limit`.

Use `--id` with an exact canonical id to inspect one object and its links, `--exact` to fetch the object whose name or form equals the text, or `--query` to match names, forms, representations or sense glosses that merely contain it. `--exact ka` returns the entry `ka` and not every entry containing "ka". Equality ignores case and Unicode normalization form. A bare form also equals an affix whose headword carries a marker, so `--exact zi` returns the stem `zi` and the prefix `zi-`, while `--exact zi-` returns only the prefix. For lexical entries, `--morph-type prefix` (names separated by commas, or morph type ids) keeps entries whose lexeme form has that morph type, so `--exact zi --morph-type prefix` returns only the prefix. An unknown morph type is refused with `grammar-read.invalid-request`, and the message lists the valid names. `--id` stands alone; `--exact` and `--query` are alternatives. The command returns the id of each object and relevant referenced ids, including natural-class members, parent categories, feature values, lexical senses, grammatical information and form environments. Lists are paged with `--cursor` (the `nextCursor` of the previous page) and `--limit`; the default page contains 25 objects and the maximum page contains 100.

The response identifies the Baseline and says whether FieldWorks has saved the project since it was captured. This reads the saved copy; it does not open or change the live FieldWorks project. Capture a Baseline before using this command.

```powershell
motif grammar read --project "C:\FieldWorks\Projects\Koro\Koro.fwdata" --kind lexical_entry --query "kat" --limit 10 --json
```
