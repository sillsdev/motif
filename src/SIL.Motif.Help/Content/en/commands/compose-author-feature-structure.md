# Author grammatical features

Stages an empty feature structure on a stem, inflectional affix or derivational affix MSA in a Draft. The MSA may already exist in the project or have been authored earlier in the same Draft. Only a person can Apply.

Use the closed input `{ "msa": "<canonical ID>" }` to name the exact MSA. A stem receives an MsFeatures structure; an inflectional affix receives an InflFeats structure for its word requirements. A derivational affix takes `"side"`, which is required for it and refused for any other MSA: `"from"` makes a FromMsFeatures structure, what the stem must carry for the affix to apply, and `"to"` makes a ToMsFeatures structure, what the derived stem carries afterwards. A stem's MsFeatures is what a word reads out, and a derivational affix's ToMsFeatures changes it: put a noun's class there (for example nc7 on *kitabu*) so an affix that requires nc7 can match it and a mismatched one cannot. An inflectional affix's InflFeats only requires: it adds no feature to the word the way a stem's MsFeatures does, but the value it requires stays on the word, so two affixes agree when both require the same value of one feature (a subject marker and a relative marker, say), and a pair that disagrees has no analysis. To make two affixes agree, give both an InflFeats structure with one value of the same feature; an entry that serves two classes needs one grammatical info for each, because a feature holds one value. On the real parser, a subject and a relative slot are accepted with matching values and rejected with mismatched ones. For singular and plural nouns, put the gender pair (for example 7/8) on the stem and the number on each class prefix: every reading shows its prefix's number, but a number requirement never rejects a stem that has none. A value a derivational affix names in its ToMsFeatures replaces the stem's value of that feature, and a feature it does not name keeps the stem's value. So a stem tagged intransitive stays intransitive through a causative until the causative's ToMsFeatures says transitive, and then an affix that requires transitive applies to the causative and not to the bare stem. A derivational affix cannot remove a feature from the word, only give it another value; to let the derived word carry no value, tag no stem with it and put the value on the stems that have it. The real parser is tested on this (`RealParserDerivedStemFeatureTests`). Other MSA types and an occupied owning slot are refused. A present structure occupies the slot even when it has no selections.

Use the returned structure identity when [authoring a feature selection](cmd:compose-author-feature-value). An empty structure is valid, and a feature can be selected before choosing its value. Selections must fit the current domain of the named structure.

Add `--cite-source <text>` and optionally `--cite-locator <text>` to record the source on every operation this command produces.
