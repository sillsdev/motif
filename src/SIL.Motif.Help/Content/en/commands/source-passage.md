Read one chapter of a Paratext Source as ordered word places. Each place includes its stable verse anchor, spelling, writing system, wordform key and any indexed reading. Approved state is unavailable.

Use `source passage --project <fwdata> --source <id> --ref "MAT 5"`. Pages contain 100 places by default, at most 200. Pass the returned opaque cursor unchanged to continue within the same Source, Passage and generation. If the generation changes, start again at the first page.

This read uses an existing index and never rebuilds it. Set the Source folder and capture the saved project to queue a refresh when the index is missing or stale.
