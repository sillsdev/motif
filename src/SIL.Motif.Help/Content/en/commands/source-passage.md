Read one Passage of a Source as ordered word places: a chapter of a Paratext Source, or a Text of the project's FieldWorks Texts. Each place includes its stable verse anchor, spelling, writing system, wordform key and any indexed reading. Approved state is unavailable.

Use `source passage --project <fwdata> --source <id> --ref "MAT 5"`. For the FieldWorks Texts, name the Source `FIELDWORKS:TEXTS` and the Text by its id; a place is the Text's segment id and word position, and its wordform key keeps the FieldWorks wordform id so homographs stay apart. Pages contain 100 places by default, at most 200. Pass the returned opaque cursor unchanged to continue within the same Source, Passage and generation. If the generation changes, start again at the first page.

This read uses an existing index and never rebuilds it. Set the Source folder (Paratext) or capture the saved project to queue a refresh when the index is missing or stale; a saved-project change makes the FieldWorks Texts index stale until it is rebuilt.
