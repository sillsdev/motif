# Author a natural class

Stages a named segment natural class with explicitly declared phoneme members in a Draft. Members may name existing phonemes or phonemes created earlier through declared dependencies. Only a person can Apply.

Add `--cite-source <text>` and optionally `--cite-locator <text>` to record the source on every operation this command produces.

## When not to use this

- Do not add a class that spans unrelated sounds; list only what the pattern needs.
- If a class with the same members already exists, reuse it rather than authoring a duplicate.
