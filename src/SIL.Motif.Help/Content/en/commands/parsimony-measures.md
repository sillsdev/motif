# List Parsimony measures

`parsimony measures` lists the fixed Parsimony checks registered in this build, their axes, evidence tiers, required capabilities, citations, and recipe links. It reads the catalog and does not invoke PanGloss.

## Example

```powershell
motif parsimony measures --project "C:\FieldWorks\Projects\Koro\Koro.fwdata" --json
```

## Related commands

- [Review grammar parsimony](cmd:parsimony) queues a selected measure.
- [Read a Parsimony view](cmd:parsimony%20view) inspects captured evidence.
