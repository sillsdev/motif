# Query values

`motif query --values classes --project <fwdata>` (or `--grammar <path>`) lists the natural classes and phonological features of the project's Baseline or of a grammar file: the names a `phon` or `env` pattern can use. The MCP tool `motif_query_schema` returns the same list with `values: "classes"`.

Each class line leads with the token to type in a pattern (the abbreviation, or the name when there is none, in brackets when it has spaces), then the full name and, for a segment class, how many phonemes it holds. A pattern may also name a class by its full name in brackets, `[Vowels]`, case-insensitively; a name with spaces can only be written that way, `[Exact featured V]`. If two classes share a name Motif refuses and lists both. PanGloss lists neither classes nor features, so the names are read from the grammar with LibLCM (about three and a half minutes on a 170 MB project; PanGloss `inventory` is to replace this); when PanGloss refuses a name as `unknown_natural_class`, Motif reads the list, resolves a full name to its abbreviation and tries again, or refuses with the closest (at most five) abbreviations and names. `--verbose` prints the stage timings to standard error. The JSON gives each class a `token`. `--json` writes `motif.query.values.v1`. See `query forms` for the pattern language.
