# Set a sense gloss

Stages the explicitly authored gloss of one sense in one writing system in a Draft. Dry Run and Trial the Draft before Finalize; only a person can Apply.

To record where the gloss came from, add `--cite-source` with the work cited and, optionally, `--cite-locator` with the page or section. The [citation](term:citation) shows beside the change when the Proposal is shown or Dry Run, and does not change what the Proposal does.
