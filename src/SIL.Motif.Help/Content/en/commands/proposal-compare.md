# Compare Proposals

Run `motif proposal compare <proposalId> <proposalId> [...] --project <fwdata> --json` to see two to eight Proposals side by side. The MCP tool `motif_proposal_compare` takes `project`, `proposalIds`, `at`, `snapshot` and `page`.

This compares each Proposal's own Trial before and after, and the approved analyses each Proposal keeps and loses. Each Proposal uses its newest completed Trial and the evidence that Trial retained, so the call measures nothing, starts no Trial and applies nothing.

The summary names each Proposal and counts of forms that gained a Reading, lost a Reading, were unchanged, were not measured and stopped early. A form a Trial did not measure on both sides is counted as not measured, never as unchanged, and an incomplete Trial makes the comparison incomplete with a typed limitation. Use `--page 1` for the form rows, 100 to a page, with diverging forms first. Each row has one cell per Proposal in request order, with the Reading IDs gained and lost. Forms are joined on writing system, form key and Reading ID.

Approved analyses are the ones the project's default user agent approves, read from the Baseline the Trials were measured on. An approved analysis counts as **kept** by a Proposal when its word's Trial after side has a Reading that is the same Reading apart from sense and does not choose a different sense: it resolves the approved sense or lists it among its candidates. It counts as **lost** when the before side yielded it and the after side no longer does, and both sides finished. An approved analysis the before side did not yield is never lost; if the after side yields it, it counts as kept, and if neither does it is in neither count. Approved analyses on forms a Trial did not measure count nowhere. Each column has `approvedKept` and `approvedLost`, and each row cell has `approvedKeptIds` and `approvedLostIds`, the approved Readings' IDs. `approvedSkippedOtherAgents` counts analyses approved only by a human agent other than the default user agent; they are not counted as approved and the comparison is incomplete with the typed limitation `approved-other-agents`.

All Trials must have been measured on one Baseline. Different Baselines refuse with `proposal.compare-baseline-mismatch` and name each Baseline. If that Baseline is no longer retained, or its approved analyses cannot be read, the call refuses with `hand-analysis.snapshot-expired` or `hand-analysis.index-unavailable`. `--at <digest>` requires each Trial to match that Baseline digest or its own Proposal revision, else `proposal.compare-at-mismatch`. A Proposal with no completed Trial refuses with `proposal.compare-trial-missing`.
