# Set a project tag

Choose the tag Motif stores for this project on this machine. A tag starts with a lowercase letter, uses lowercase letters, digits and hyphens, contains at most ten characters, and must be unused by every other Known project.

```text
motif project tag --set cebu --project <fwdata>
```

Use `--json` to receive the saved tag as structured output. The new tag remains in place when Motif records the project again.
