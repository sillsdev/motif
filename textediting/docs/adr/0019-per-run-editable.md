# Editability is a run property, as in FieldWorks

The field honours FieldWorks' editable property on each run: not editable, editable, or semi-editable. The caret
moves to the nearest place where editing is allowed. Delete, cut and paste are disabled when a selection crosses text
that may not be edited. Text that may not be edited is not spell-checked unless the run forces checking.

Owner decision, 2026-11-03.
